# 项目执行提示词说明

`prompts/project_run/` 是真实项目执行时使用的固定提示词包，不是搭建母版时使用的脚本。

## 使用原则

- 一次只执行一个阶段。
- 每个阶段完成后必须停止，等待用户确认。
- 不允许一上来跑完整个项目。
- 不允许默认行业。
- 不允许虚构字段、数据或结论。
- 所有指标必须有明确业务口径。
- 所有结论必须能追溯到真实数据。
- 如果字段缺失，必须说明并跳过不支持的分析模块。
- 如果需要用户手动操作，必须使用固定提醒格式。

## 自动执行与交付

SQL 阶段使用临时 MySQL 8.0 自动执行、校验和导出；Power BI 阶段根据本次结果生成报表 YAML 与可编辑 PBIP。支持的组件无需手动拖字段或复制 DAX。Desktop 刷新、数值和交互检查在工程生成后完成。按阶段确认不等于逐条 SQL 或逐个组件等待用户操作。详见 [SQL 自动执行说明](SQL自动执行说明.md) 和 [Power BI 自动生成说明](PowerBI自动生成说明.md)。
