# 手动操作提醒规范

## 核心规则

当某个步骤 Codex 无法替用户完成，或者需要用户在外部软件中操作时，必须主动停止并提醒。不能假装已经完成需要用户手动完成的步骤。

## 固定格式

```text
【需要你手动操作】
操作目标：
为什么需要你操作：
具体步骤：
完成后你应该看到：
如果报错怎么办：
完成后请回复我什么：
```

## 常见场景

### 放入原始数据

- 把 CSV / Excel / JSON 放到 `data/raw/`。
- 不要修改原始文件。
- 放好后回复“原始数据已放入 data/raw”。

### 创建 MySQL 数据库

- 打开 Navicat。
- 新建 MySQL 连接或打开已有连接。
- 新建数据库，字符集建议 `utf8mb4`。
- 排序规则建议 `utf8mb4_general_ci` 或 `utf8mb4_0900_ai_ci`。
- 数据库名建议使用项目英文短名。

### 运行 SQL

- 先运行 `sql/01_ods/`。
- 再运行 `sql/02_dwd/`。
- 再运行 `sql/03_ads/`。
- 最后运行 `sql/04_checks/`。
- 在 Navicat 中打开查询窗口，粘贴或打开 SQL 文件，点击运行。
- 如果报错，复制完整报错和出错 SQL 文件名给 Codex。

### 导入 CSV 到 MySQL

- 右键目标表，选择导入向导。
- 选择 CSV 文件。
- 确认编码、字段分隔符、是否包含标题行。
- 检查字段类型。
- 导入后执行行数检查。

### 导出 ADS 表

- 在 Navicat 中右键 ADS 表。
- 选择导出向导。
- 导出为 CSV / Excel。
- 保存到 `outputs/tables/`。
- 文件名建议与 ADS 表名一致。

### 配置 OpenAI Images API

- 在 Windows PowerShell 临时设置：`$env:OPENAI_API_KEY="你的key"`。
- 不要把 API Key 写进代码。
- 如果不会配置，使用 `powerbi_notes/image_prompts.md` 手动生成图片。

### 运行 BI 样例图脚本

- 运行 `python scripts/generate_bi_mockups_with_openai.py`。
- 检查 `outputs/bi_mockups/` 是否生成 PNG。
- 如果报错，复制完整报错给 Codex。

### Power BI 导入数据

- 打开 Power BI Desktop。
- 点击“获取数据”。
- 选择 MySQL 数据库或 Text/CSV。
- 选择 ADS 表或导出的 CSV。
- 加载后检查字段名是否显示正确。

### Power BI 搭页面

- 按 `powerbi_notes/page_xxx.md` 操作。
- 每个视觉对象必须明确字段拖放位置。
- 页面完成后截图保存到 `outputs/bi_screenshots/`。

### 最终截图与 README

- README 优先引用 Power BI 实际截图或 `outputs/bi_mockups/`。
- 不要引用 Python 诊断图作为最终展示图。

## 阶段结束格式

每次执行阶段结束时，必须输出：

```text
下一步是否需要你手动操作：
如果需要，具体操作是什么：
操作完成后，请回复我什么：
```
