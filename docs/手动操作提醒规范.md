# 手动操作提醒规范

## 核心规则

当某个步骤 Codex 无法替用户完成，或者需要用户在外部软件中操作时，必须主动停止并提醒。不能假装已经完成需要用户手动完成的步骤。

## 固定格式

```text
【需要你手动操作】
操作目标：
为什么需要你操作：
具体步骤：
完成后你应该看到：
如果报错怎么办：
完成后请回复我什么：
```

## 常见场景

### 放入原始数据

- 把 CSV / Excel / JSON 放到 `data/raw/`。
- 不要修改原始文件。
- 放好后回复“原始数据已放入 data/raw”。

### 准备 SQL 执行环境

- 默认使用临时 MySQL 8.0。若执行环境缺少 Docker 引擎或可用的 MySQL 8.0 二进制，说明缺少条件及准备步骤，见 [SQL 自动执行说明](SQL自动执行说明.md)。
- 环境可用且项目、口径与 SQL 已确认后，由执行器连续完成 ODS、导入、DWD、ADS、校验、导出、建模字段提取和实例清理。
- 不要求用户打开 Navicat、逐层运行 SQL 或手动导入导出。结果保存在 `outputs/runs/<run_id>/` 的 `tables/`、`model/`、`source/` 及运行清单中。
- 只有用户选择 `existing` 模式时，才需要提供已有库连接配置；密码只在本机环境变量中设置。
- 失败时读取本次 `run.json` 定位问题，不把预览、部分结果或旧运行视为执行成功。

### 配置 OpenAI Images API

- 在 Windows PowerShell 临时设置：`$env:OPENAI_API_KEY="你的key"`。
- 不要把 API Key 写进代码。
- 如果不会配置，使用 `powerbi_notes/image_prompts.md` 手动生成图片。

### 运行 BI 样例图脚本

- 运行 `python scripts/generate_bi_mockups_with_openai.py`。
- 检查 `outputs/bi_mockups/` 是否生成 PNG。
- 如果报错，复制完整报错给 Codex。

### 打开并验收 Power BI 工程

- `scripts/generate_powerbi.py` 根据报表 YAML 自动生成数据接入、模型、支持的 DAX、主题及原生组件。无需用户重新导入 CSV、复制 DAX 或逐项搭页面。
- 若工程包含启动器，运行 `OpenReport.cmd` 设置 DataRoot 并打开 PBIP；`launcher: false` 时直接打开 PBIP，按工程说明核对 DataRoot。
- 路径变化或启动器受策略限制时，在“转换数据 → 管理参数”中将 DataRoot 设置为本工程 `data` 文件夹的完整路径，再关闭并应用；无需更改系统安全策略。
- 在 Desktop 点击刷新，检查字段、数值、单位、文字、日期、筛选和联动，再保存截图至 `outputs/bi_screenshots/`。实际检查前保持 `desktop_validated: false`。
- 仅对生成器尚不支持且本项目确需的组件或交互，交接具体扩展步骤。详见 [Power BI 自动生成说明](PowerBI自动生成说明.md)。

### 最终截图与 README

- README 优先引用 Power BI 实际截图或 `outputs/bi_mockups/`。
- 不要引用 Python 诊断图作为最终展示图。

## 阶段结束格式

每次执行阶段结束时，必须输出：

```text
下一步是否需要你手动操作：
如果需要，具体操作是什么：
操作完成后，请回复我什么：
```
