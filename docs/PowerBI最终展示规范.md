# Power BI 最终展示规范

## 定位

Power BI 是项目最终可视化工具。README、报告、简历和面试讲解应优先引用 Power BI 实际截图、BI 样例图或 Power BI 页面设计说明。

## 页面设计要求

设计前读取 [报表设计 Skill](../.agents/skills/powerbi-report-design/SKILL.md)。统一质量标准，按实际业务与数据选择页面：默认充分利用画布、不放装饰性侧栏；用有区别的画布、内容表面和低饱和分析分区建立层次；颜色角色依据指标含义配置，同一指标跨页一致。金额卡片依据数量级将单位放在数值后，使用数值型 DAX 和格式字符串；图表与明细单位须可解释、可对账。

不规定固定页数、指标卡数量或“四卡两图一表”。没有必要的组件应省略，并在页面说明中记录原因；下文各项仅针对本页实际使用的组件填写。

每一页必须对应一个明确业务问题，并基于真实 ADS 表和真实字段生成：

- 页面名称。
- 页面业务目标。
- 页面布局草图说明。
- 指标卡内容。
- 图表类型。
- 使用的数据表。
- 使用的字段。
- 筛选器。
- 排序规则。
- 数据标签规则。
- 交互筛选规则。
- 报表 YAML 中的模型、指标和组件绑定，以及生成和验收步骤。
- 页面讲解话术。
- OpenAI Images API 图片生成提示词。

## 自动生成与说明粒度

根据本次成功 SQL 运行与审核后的报表 YAML，使用 `scripts/generate_powerbi.py` 生成可编辑工程。自动接入 CSV、建立显式配置的模型关系、写入支持的 DAX、生成主题与原生图表。无需逐项复制代码或拖字段。

每页说明必须记录：

- 数据来源、ADS 表、真实字段和指标公式。
- 显式关系、基数和筛选方向；不能按字段名称猜测关系。
- 各组件类型与字段、度量值绑定，标题、排序、标签和筛选规则。
- 页面布局、颜色角色、字体和单位，及其在报表 YAML 中的配置。
- 生成命令、输出工程位置、DataRoot 与 Desktop 打开、刷新、对账和截图步骤。

当前支持指标卡、竖向柱状图、横向条形图、折线图、明细表和筛选器。自动布局与支持边界见 [主题与布局说明](PowerBI设计升级说明.md)。超出能力的组件或交互单独标注；确需用户扩展时才补充字段拖放级步骤。

## 验收

先检查结构、引用、位置和单位缩放，再在 Desktop 中刷新、校对数值和显示、检查筛选联动并截图。生成成功或样例图不能替代实际验收；每份新工程默认保持 `desktop_validated: false`，直至该工程完成实际检查。

## 限制

- 不允许套用电商模板。
- 不允许生成与真实数据字段无关的图。
- 不允许依赖 BI 样例图中的文字作为精确指标来源。
- 精确指标数值必须写入 `powerbi_notes/page_xxx.md`。
