# Power BI 最终展示规范

## 定位

Power BI 是项目最终可视化工具。README、报告、简历和面试讲解应优先引用 Power BI 实际截图、BI 样例图或 Power BI 页面设计说明。

## 页面设计要求

设计前读取 [报表设计 Skill](../.agents/skills/powerbi-report-design/SKILL.md)。统一质量标准，按实际业务与数据选择页面：默认充分利用画布、不放装饰性侧栏；用有区别的画布、内容表面和低饱和分析分区建立层次；颜色角色依据指标含义配置，同一指标跨页一致。金额卡片依据数量级将单位放在数值后，使用数值型 DAX 和格式字符串；图表与明细单位须可解释、可对账。

不规定固定页数、指标卡数量或“四卡两图一表”。没有必要的组件应省略，并在页面说明中记录原因；下文各项仅针对本页实际使用的组件填写。

每一页必须对应一个明确业务问题，并基于真实 ADS 表和真实字段生成：

- 页面名称。
- 页面业务目标。
- 页面布局草图说明。
- 指标卡内容。
- 图表类型。
- 使用的数据表。
- 使用的字段。
- 筛选器。
- 排序规则。
- 数据标签规则。
- 交互筛选规则。
- Power BI 具体操作步骤。
- 页面讲解话术。
- OpenAI Images API 图片生成提示词。

## 操作步骤粒度

Power BI 操作步骤必须写到新手可以照着做：

- 获取数据方式。
- 选择哪些 ADS 表。
- 模型视图如何关联表。
- 新建度量值的位置。
- 每张图选择哪个视觉对象。
- X 轴、Y 轴、图例、值区域、筛选器分别拖哪个字段。
- 数据标签在哪里打开。
- 排序按哪个字段。
- 标题怎么写。
- 页面大小怎么设置。
- 指标卡放在哪一行。
- 图表放在左边、右边还是下方。

## 限制

- 不允许套用电商模板。
- 不允许生成与真实数据字段无关的图。
- 不允许依赖 BI 样例图中的文字作为精确指标来源。
- 精确指标数值必须写入 `powerbi_notes/page_xxx.md`。
