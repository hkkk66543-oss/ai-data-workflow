# 母版升级说明

## 本次升级目标

本次升级在现有通用 AI 数据分析工作流母版基础上增量改造，不删除已有项目结构，不推翻重建。

## 升级内容

- SQL 默认改为简约中文表名和字段名，并要求生成中英文命名映射表。
- Python 从最终展示图生成工具调整为数据质量检查、辅助 EDA 和 SQL 结果校验工具。
- Power BI 明确为最终可视化工具。
- BI 样例图由 OpenAI Images API 或图片提示词生成。
- 新增固定项目执行提示词包 `prompts/project_run/`。
- 新增手动操作提醒规则，要求 Codex 在外部软件步骤前主动停止并说明具体操作。
