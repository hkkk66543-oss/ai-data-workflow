# 工作流功能与使用说明

本母版用于不同业务场景的数据分析，使用通用十阶段流程：

Context / Data Understanding → Domain Identification → Brainstorming → Plan → Work-Plan → Execute → Test / Verify / QA → Review → Learn → Reuse。

## SQL 执行

确认主题、指标口径和计划后，生成中文命名的 MySQL 8.0 SQL 与 `sql_pipeline` 配置。执行器先预览，再在已授权范围内使用临时 MySQL 自动完成 ODS、导入、DWD、ADS、校验和导出；保留结果表、建模字段、实际 DDL、源码与执行报告，清理临时实例。已有 MySQL 为可选模式。详见 [SQL 自动执行说明](SQL自动执行说明.md)。

## Power BI 交付

根据本次成功 SQL 结果和已确认业务问题生成报表 YAML、设计说明及可编辑 PBIP 工程，包括 CSV 接入、模型、支持的 DAX、主题与六种数据组件。布局、配色和单位根据实际数据选择，详见 [自动生成说明](PowerBI自动生成说明.md) 和 [主题与布局说明](PowerBI设计升级说明.md)。

使用者在 Desktop 打开、刷新、核对数值和显示、检查联动并截图。超出生成器能力的组件或交互单独交接。

## Python 与样例图

Python 用于数据质量、辅助 EDA、异常识别、SQL 执行及结果校验。诊断图只用于内部检查。Power BI 是最终可视化工具；OpenAI Images API 或图片提示词可用于布局参考，图片生成不阻断 PBIP 交付。

## 项目入口

从 `prompts/project_run/01_项目启动_数据理解与行业识别.md` 开始，按阶段确认。真实字段与业务口径始终是前提；不修改原始数据，不虚构背景、数据或结论。
