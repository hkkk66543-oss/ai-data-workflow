## 实施

- 设计页面的筛选器显式使用 Dropdown，隐藏重复字段头，放大选项文字；预留 128px 高度。不再在短容器里显示可滚动列表。
- 对 date 类型的折线/柱状图明确设置 categoryAxis.axisType=Categorical，沿用字段 yyyy-MM-dd 格式。datetime 类型仍保留连续时间轴，不抹掉真实小时粒度。
- 重新分配 FHD 页面空间：双图+明细场景的指标卡从 144px 调整至 128px，分析图高 256px，明细表从 192px 增至 288px；对应分区标题同步移动。继续阻断重叠、越界和分析图高度小于 240px 的布局。
- 指标数值 40pt、图表标题 16pt、分类轴与数据标签 14pt、数值轴 12pt、表格表头/内容 14pt，说明与分区文字也放大。
- 原生组件显式写入关键格式，避免只依赖主题继承。关闭自动重复副标题，保留主题配色和表格自适应列宽。

3 套示例仍使用三行合成数据，未筛选时 3 / 60.50，A 为 2 / 30.50。数据校验和与上一版一致。
