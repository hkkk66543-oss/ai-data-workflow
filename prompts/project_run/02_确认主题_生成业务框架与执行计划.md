# 02 确认主题：生成业务框架与执行计划

请只执行本阶段。执行前必须读取 `docs/数据字典.md`、`docs/数据质量报告.md`、`docs/表关系说明.md`、`docs/行业识别报告.md`。

任务：

1. 基于已确认或待确认的行业方向，生成 `docs/项目选题建议.md`。
2. 结合真实字段设计业务分析框架，生成 `docs/业务分析框架.md`。
3. 为每个指标先写业务口径，再写后续 SQL / Python 计算思路，生成 `docs/指标口径.md`。
4. 生成 `docs/执行计划.md`，明确 SQL、Python、Power BI、报告阶段的边界。

规则：

- 如果用户确认的项目主题与自动识别不同，以用户确认结果为准，但必须标注依据和风险。
- 行业模板只能提供思路，不能替代真实字段判断。
- 不允许虚构当前数据不支持的分析模块。
- 不允许默认使用电商指标。
- 如果字段缺失，必须说明该模块无法执行或只能作为待扩展方向。

阶段结束时必须停止，等待用户确认执行计划后才能进入 SQL 阶段。

阶段结束时必须输出：

```text
下一步是否需要你手动操作：
如果需要，具体操作是什么：
操作完成后，请回复我什么：
```
