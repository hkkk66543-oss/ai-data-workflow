# 01 项目启动：数据理解与行业识别

请只执行本阶段，不要继续生成 SQL、Python、Power BI 或最终报告。

任务：

1. 扫描 `data/raw/` 中的真实文件，不修改原始数据。
2. 识别文件格式、编码、行数、列数、字段类型、缺失情况、重复情况和样例数据。
3. 生成 `docs/数据字典.md`。
4. 生成 `docs/数据质量报告.md`。
5. 生成 `docs/表关系说明.md`。
6. 基于字段名、表名、样例数据和业务含义执行行业识别。
7. 生成 `docs/行业识别报告.md`。

规则：

- 不允许默认行业。
- 不允许虚构字段、数据、业务背景和结论。
- 如果行业不明确，输出 2-3 个可能方向并标注判断依据。
- 不允许在行业未确认前套用电商指标。
- 如果字段含义不明确，先根据字段名和样例数据推测，并标注“待确认”。

```text
如果报错怎么办：如果文件太大或无法复制，请告诉我文件格式、大小和报错信息。

```
