# 项目执行提示词包使用说明

本文件夹用于真实数据分析项目执行，不用于搭建母版。以后每个真实项目按以下顺序使用：

1. 复制母版文件夹。
2. 改成新项目名。
3. 把原始数据放进 `data/raw/`。
4. 使用 `01_项目启动_数据理解与行业识别.md`。
5. 检查 `docs/数据字典.md`、`docs/数据质量报告.md`、`docs/表关系说明.md`、`docs/行业识别报告.md`。
6. 确认项目主题。
7. 使用 `02_确认主题_生成业务框架与执行计划.md`。
8. 检查 `docs/项目选题建议.md`、`docs/业务分析框架.md`、`docs/指标口径.md`、`docs/执行计划.md`。
9. 确认执行计划。
10. 使用 `03_确认计划_生成SQL.md`。
11. 按 `docs/SQL自动执行说明.md` 配置本机连接，先预览，再经授权执行 SQL 流水线。
12. SQL 报错时使用 `04_SQL报错修复.md`。
13. SQL 跑通后使用 `05_SQL结果_QA校验.md`。
14. 使用 `06_生成Python_EDA与数据校验.md`。
15. 使用 `07_生成PowerBI方案.md`。
16. 按样例 BI 图和详细操作步骤手动搭建 Power BI 看板。
17. 使用 `08_生成报告_README_简历_面试稿.md`。
18. 使用 `09_项目复盘_更新母版经验.md`。

通用规则：

- 项目主题、指标口径、执行计划和数据库执行范围由我确认。
- SQL 在授权范围内连续执行导入、分层计算、校验和导出；失败即停。其他阶段完成后仍等待确认。
- 不允许一上来完整跑完整个项目。
- 不允许默认行业。
- 不允许虚构字段、数据、结论。
- 所有指标必须有明确业务口径。
- 所有结论必须能追溯到真实数据。
- 如果字段缺失，必须说明，不允许自己编字段。
- 如果当前数据不支持某个分析模块，必须跳过并说明原因。
- 如果某个步骤需要我手动操作，必须提醒我并给出具体操作步骤。

手动操作提醒固定格式：

```text
【需要你手动操作】
操作目标：
为什么需要你操作：
具体步骤：
完成后你应该看到：
如果报错怎么办：
完成后请回复我什么：
```

阶段结束时必须输出：

```text
下一步是否需要你手动操作：
如果需要，具体操作是什么：
操作完成后，请回复我什么：
```
