# 09 项目复盘：更新母版经验

请只执行本阶段。执行前必须确认当前项目的报告、README、简历描述和面试稿已完成。

任务：

1. 复盘本项目中可复用的分析方法、SQL 命名、Power BI 页面设计和手动操作经验。
2. 更新 `docs/经验总结.md`。
3. 如有必要，补充 `domain_packs/` 中对应行业模板，但不得覆盖真实项目结论。
4. 如有必要，更新 `prompts/project_run/` 中的提示词，但必须保持通用性。
5. 输出本项目可复用经验和不应复用的限制。

规则：

- 不允许把某个项目的特定字段当成通用字段。
- 不允许把某个行业的指标默认套到所有行业。
- 不允许删除母版已有结构。
- 更新母版经验时必须说明来源项目和适用边界。

阶段结束时必须输出：

```text
下一步是否需要你手动操作：
如果需要，具体操作是什么：
操作完成后，请回复我什么：
```
