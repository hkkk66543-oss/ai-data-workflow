# Power BI 布局参考

状态：待真实 ADS 表、字段和页面业务问题确认后细化。

## 布局原则

- 每页只回答一个核心业务问题。
- 首页通常回答“整体表现怎么样”，但具体内容由真实行业和字段决定。
- 后续页面围绕原因拆解、对象分层、趋势变化、异常风险或行动建议展开。
- 每页不超过 6 个核心视觉对象。
- 指标卡、趋势图、结构图、明细表和筛选器之间必须有清晰层级。

## 页面操作说明要求

每页必须写明：

- 页面大小怎么设置。
- 指标卡放在哪一行。
- 左侧、右侧、下方分别放什么图。
- 每张图选择哪个视觉对象。
- X 轴拖哪个字段。
- Y 轴拖哪个字段。
- 图例拖哪个字段。
- 值区域拖哪个字段或度量值。
- 筛选器拖哪个字段。
- 数据标签在哪里打开。
- 排序按哪个字段。
- 标题如何设置。
