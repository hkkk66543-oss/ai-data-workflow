# Power BI 布局参考

状态：待真实 ADS 表、字段和页面业务问题确认后细化。

## 布局原则

- 每页只回答一个核心业务问题。
- 首页通常回答“整体表现怎么样”，但具体内容由真实行业和字段决定。
- 后续页面围绕原因拆解、对象分层、趋势变化、异常风险或行动建议展开。
- 按问题与可读性控制组件数量；超出布局容量时拆页，不固定每页组件组合。
- 指标卡、趋势图、结构图、明细表和筛选器之间必须有清晰层级。

## 自动生成配置要求

先读取 [报表设计 Skill](../.agents/skills/powerbi-report-design/SKILL.md)。每页说明及报表 YAML 必须写明：

- 页面名称、业务问题和画布大小。
- `layout`：auto、overview、comparison、detail 或 manual；manual 用于在 YAML 中显式配置位置。
- 真实表、字段、度量值与各组件的绑定。
- 图表类型、标题、排序、数据标签及筛选字段。
- `design.palette`、`design.colors` 与组件 `role`、`fill`、`color`、`show_labels`。
- 金额展示单位及与原值的对账方式。
- 生成工程入口、DataRoot 路径与验收项目。

生成器负责创建支持的原生组件和布局，无需用户逐项设置。自动布局使用 1920×1080 画布，检查边界和重叠；其他画布或特殊布局在 YAML 中明确坐标。布局容量与配置边界见 [主题与布局说明](../docs/PowerBI设计升级说明.md)。

## 扩展与验收

需要生成器尚不支持的视觉对象或交互时，单独列出扩展范围；确需用户操作才写字段拖放步骤。生成工程后在 Desktop 刷新，检查标签截断、日期粒度、单位、筛选和联动，记录实际截图检查结果。
