# DAX 指标模板

状态：待真实 ADS 表、字段和指标口径确认后生成。

## 规则

- 每个 DAX 度量值必须能回溯到 `docs/指标口径.md`。
- DAX 表名和字段名应优先使用 Power BI 中显示的中文名称。
- 如果字段来自中文 SQL 表名或中文视图，DAX 必须使用对应中文字段。
- 不在行业未确认前创建 GMV、DAU、逾期率、完课率、Offer 率等行业专属 DAX。
- 不允许引用不存在的字段。

## 占位模板

```DAX
核心对象数 = DISTINCTCOUNT('应用_待确认分析'[对象编号])
```

```DAX
核心事件数 = SUM('应用_待确认分析'[事件数])
```

```DAX
转化率 = DIVIDE([目标对象数], [基础对象数])
```

以上为占位示例，真实项目中必须替换为已确认 ADS 表和字段。
