# Power BI 看板方案模板

状态：待真实项目完成行业识别、指标口径、SQL ADS 表和 QA 校验后细化。

## 生成原则

- 自动判断当前项目需要几页看板，不固定页数。
- 每一页必须回答一个明确业务问题。
- 页面设计必须基于真实 ADS 表、真实字段和已确认指标口径。
- 不允许套用电商模板。
- 不允许使用当前数据不存在的字段。

## 每页必须输出

- 页面名称。
- 页面业务目标。
- 页面布局草图说明。
- 指标卡内容。
- 图表类型。
- 使用的数据表。
- 使用的字段。
- 筛选器。
- 排序规则。
- 数据标签规则。
- 交互筛选规则。
- Power BI 具体操作步骤。
- 页面讲解话术。
- OpenAI Images API 图片生成提示词。

## 需要用户手动操作

Power BI Desktop 页面需要用户手动搭建。真实项目中必须在每个 `page_xxx.md` 中写明字段拖放级别的步骤，并提醒用户截图保存到 `outputs/bi_screenshots/`。
